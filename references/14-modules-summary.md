# modules/ 内容摘要表规范

> V2.3 新增。对标倪海厦 skill（nihaixia）SKILL.md 内置的「modules/ 内容摘要」节。
> 用途：让 AI 一眼看清每个模块覆盖什么、什么问题加载哪个模块，避免盲目加载全文。

## 为什么需要

modules/ 里的讲稿原文可能很大（几 MB）。如果 AI 每次回答都盲目搜索所有模块，效率低且容易串内容。摘要表让 AI **先看摘要定位，再精准加载**。

## 模板

在 SKILL.md 中"关键词索引"之后、"角色扮演规则"之前，写入：

```markdown
## modules/ 内容摘要

| 模块 | 覆盖内容 | 适用问题 | 加载时机 |
|------|---------|---------|---------|
| modules/01_shanghan.md | 伤寒论太阳病篇 129 条 | 六经辨证/桂枝汤/麻黄汤 | 条文解读、经方选方时 |
| modules/02_jingui.md | 金匮要略 23 篇 | 杂病/妇人病/水气病 | 金匮相关问题时 |
| modules/03_yian.md | 849 个医案 | 临床案例参考 | 辨证对比、疗效佐证时 |
| … | … | … | … |
```

## 填充要求

| 列 | 来源 | 要求 |
|----|------|------|
| 模块 | 实际文件名 | 与目录一致 |
| 覆盖内容 | 讲稿章节结构 | 一句话概括 + 关键篇目 |
| 适用问题 | 该模块能回答的问题类型 | 写用户会怎么问（如"失眠怎么治"→金匮/内经） |
| 加载时机 | 什么情况才需要打开 | 明确"简单问题不加载，复杂条文才加载" |

## 加载规则（写在摘要表之后）

```markdown
**加载规则**：
- 简单问题（养生/基础辨证）→ 直接用 SKILL.md 速查表回答，不加载模块
- 具体条文问题 → 加载 modules/0X_xxx.md
- 医案参考 → 按疾病类型加载 cases/
- 深度理论 → 加载 modules/0X_xxx.md 对应章节
```

> 原则：**能速查就不加载，能加载摘要就不加载全文**。分级响应，控制 token 消耗。
