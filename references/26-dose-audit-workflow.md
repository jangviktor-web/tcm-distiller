# 26 · 剂量勘误工作流（S7/S8/S9）

> 来源：倪海厦 skill 258 方剂量全量勘误实战（2026-08-13）——勘误表输出 → 二次检测 → P0-P3 分级修复全链路方法论。
> 适用：任何经方/方剂型中医 skill 的剂量质量保障；Pipeline B（增量优化）在 B3/B5 之间执行。

## 一、触发时机

- 新蒸馏 skill 含方剂剂量 → Phase 4 增量补充时执行
- 已有 skill 用户要求"剂量勘误/核对" → Pipeline B 执行
- skill 中剂量曾被 judge/用户质疑 → 立即执行

## 二、S7 · 剂量勘误五步工作流

### Step 1：建立方剂全清单
- 从源文件提取全部方剂名（伤寒/金匮等），**合并去重**（同名异书只留一个），按拼音排序生成清单
- 产出去重排序清单文件

### Step 2：对照源文件逐方提取（分批输出）
对每一方提取三要素，按批次输出表格（每批 ≤50 方）：

| 列 | 内容 |
|---|---|
| 序号 | 清单顺序 |
| 方剂名 | 与清单一致 |
| 原文出处 | 书·篇（含源文件行号） |
| 古代原方剂量 | 源文件方行逐字（含行号） |
| 人物临床经验剂量 | 源文件讲课中的"钱/两"临床叙述（含行号）——**无临床叙述写"文字稿未涉及"，不得编造** |
| skill 当前记录 | 现状简述 |
| 问题类型 | 合格 / 错误 / 混淆 / 缺失 / 合格+缺失 / 无法核对 |
| 校正建议 | 可执行的具体改法 |

**问题类型定义**：
- 合格：剂量与源文件吻合
- 错误：剂量数字与源文件不符（需改）
- 混淆：版本差异未标注（倪师版 vs 通行本）
- 缺失：skill 无古方剂量或无临床剂量
- 无法核对：源文件确无方行（**先穷尽搜索：异名/异字/方行拆行，确认无再标**——本会话 17 处初判"无法核对"实为漏检的教训）
- 合格+缺失：古方对但临床缺（或反之）

### Step 3：二次检测（勘误表自身的勘误）
派 **3 组独立子 agent**（按方剂区间分段）对照源文件抽核：
- 剂量引用是否与源文件一致（行号+数字）
- 问题类型判定是否合理
- 校正建议是否可行
- 是否漏判（标"合格"的方实际有误）
- **子 agent 结论必须以源文件原文为准**（本会话教训：子 agent 2 次误报剂量——甘草粉蜜汤白粉实为二两、红蓝花酒实为二两；2 次误报"无方行"——鳖甲煎丸/白头翁汤实有方行；均以源文件逐字核验纠正）

### Step 4：分级修复（P0-P3）
> ⚠️ **命名区分**：S7 的 P0-P3 是**剂量错误分级**（P0 硬错误→P1 速查表→P2 缺失→P3 未列），与 Pipeline B 的 P0-P5 **优化优先级**（B3 定向增强）是两套独立体系，勿混用。

| 级别 | 内容 | 示例 |
|---|---|---|
| P0 | 模块层剂量**硬错误**（数字错） | 橘皮竹茹汤三处错（二斤→二升/二两→五两/三两→一两） |
| P1 | **速查表/索引层**错误重写 | 感冒速查表 6 方比例错（麻黄汤比例颠倒/小柴胡等量错） |
| P2 | 缺失补齐（原方剂量+临床剂量） | 补 10 方原方剂量、7 方临床剂量 |
| P3 | 完全未列方补入 | 差后劳复 5 方 + 附方 2 方 |

**每处修改三连**：file_edit 修改 → grep 验证生效（旧值清零）→ 全量改完 ima_skill_create 注册 → **注册后复查**（平台快照覆盖本地风险，见 CHANGELOG 血泪经验）

**多文件同知识全量核验（V4.3 新增·酸枣仁汤残留教训）**：同一方剂/知识常出现在多个文件（SKILL.md 速查卡、modules 讲解、references 蒸馏表）——修复时必须 `grep -rn "关键词"` 全库核验**所有位置**，只改一处=遗漏（倪海厦实测：modules/05 芎藭一两已对，但 SKILL.md 速查卡"芎䓖二两"残留至负优化审计才被作答 agent 抓出）。

### Step 5：汇总报告
产出勘误汇总报告：统计总览（合格/错误/缺失/未列/无法核对）+ **高优先级修正清单 Top10**（每项附源文件行号+正确值+修复状态）+ 遗留问题 + 交付物清单。

## 三、S8 · 版本差异处理规范（防误判）

**核心铁律：以源文件（人物讲课版）为准。**

- 人物讲课剂量与通行本多处不同属**正常**（本会话实例：小青龙五味子半斤 vs 宋本半升、大青龙杏仁50/姜2两/枣12枚 vs 宋本40/3/10、柴胡加龙骨牡蛎无黄芩、黄连汤干姜二两人参三两、大柴胡枳实四两大黄二钱、小柴胡人参二两 vs 宋本三两）
- **测试/评估时禁止用通行本衡量源文件版剂量**——本会话 judge 7 处误判的根源
- 版本差异必须显式标注（"倪师讲课版 vs 宋本通行本"），两套并存不互纠
- 用户对照通行本质疑时：给出两版并说明差异，不强行二选一
- 同一方在源文件两书（伤寒稿/金匮稿）剂量不同：两版并存 + 给人物临床实际用量的回答口径（本会话实例：桃花汤干姜伤寒一两/金匮二两，倪师临床分别开 1钱/2钱——恰好印证直换铁律）

## 四、S9 · 剂量三体系换算标准（通用化）

| 体系 | 换算 | 用途 |
|---|---|---|
| ① 古代考证 | 汉朝 1两≈15.625g、1斤≈248g；1升=200ml | 仅用于理解原方规模/配伍比例、古籍对照——**不是开方依据** |
| ② 台湾临床 | 1钱=3.75g、1两=37.5g、1斤=600g | 台湾度量衡下的临床开方单位 |
| ③ **临床直换铁律** | **古方一两 = 临床一钱**（≈3.3g 大陆/3.75g 台湾） | **人物未特别说明剂量的方一律按此换算开方**（神农本草经源161-184："汉朝的1两就是现在的1钱"） |

要点：
- 1升=小酒杯（杯口1寸底6分），半夏1升≈1钱（颗粒状）；花类轻药按质地（金银花/蝉蜕 1斗≈5分-1钱）
- 人物取整钱数开方（"心里知道2.3钱，开三钱算了"）
- 三套分别换算、严禁混用、不互折
- 换算标准必须写入产出 skill 的 SKILL.md（含临床直换铁律），防 judge 用考古换算误判

### S9b · 实物单位换算表（非"两"单位，V4.4b 新增·nihaixia 源稿附录 L4977+四出处口述）

「古方一两=临床一钱」只覆盖"两"；"枚/升/个/斤/合/尺/握"等必须查下表（源文件附录度量衡表 + 人物课程口述）：

| 实物单位 | 换算（汉制考证） | 人物临床口述 |
|---|---|---|
| **附子** | 大者1枚=20-30g、中者1枚=15g | **一枚≈3-4钱**（四出处一致：茯苓四逆汤"约三钱四钱"、白通汤"大五钱小三钱"、通脉四逆加猪胆汁"约三钱有时四钱"、白术附子汤"炮炙后约三钱半"） |
| **升（容积）** | 1升=200ml；半夏一升=130g、五味子/蜀椒/吴茱萸一升=50g、葶苈子一升=60g、虻虫一升=16g | "一升约五钱的量"（桂枝汤讲解）——**颗粒药临床直接给钱数（如半夏2-5钱），不以升换算** |
| **方寸匕** | 金石类2.74g、草木药末约1g | 半方寸匕=一刀圭=一钱匕=1.5g；一钱匕=1.5-1.8g；梧桐子大=黄豆大≈2g |
| **枚/个/尺/握** | 杏仁大者10枚=4g；栀子10枚≈15g；瓜蒌1枚≈46g；枳实1枚≈14.4g；石膏鸡蛋大1枚≈40g；厚朴1尺≈30g；竹叶一握≈12g；乌头1枚小者3g、大者5-6g | 人物口述有直接钱数的用口述（如大陷胸丸弹丸大约1钱） |

**规则**：非"两"单位 → ①人物口述钱数优先 → ②查上表换算（可转钱）→ ③仍无对应才保留原单位标注"按原方"。

## 六、与既有模块的衔接（V4.0）

- **行号用途区分**：勘误溯源用行号（审计定位、对照源文件）是允许的；但**产出 skill 的 SKILL.md 检索索引禁止行号**（V3.6 规范：一律 `文件 搜"关键词"`，行号只留独立 INDEX 文件且脚本校验）——勘误报告里的行号是工作底稿，不进入产出 skill 正文
- **S7 ↔ S3/21-acceptance-testing**：剂量勘误（源文件对照）与验收测试（50 题热度实测）互补——先勘误后测试，测试题中的剂量答案以勘误结果为准
- **S7 ↔ S4 知识网络体检**：勘误发现的"未列方"补入后，S4 体检验证索引可达
- **S8 ↔ S2 强制原文引用**：版本差异标注是原文引用的子集，引用剂量必注版本（讲课版/通行本）
- **S9 ↔ 维度6**（dimensions.md）：维度6 产出必须含三体系换算表（含临床直换铁律），S9 是维度6 的通用基准
- **S10 ↔ 18-error-handling**：S10 是预防性纪律（标注/复核/防回滚），18 是出错后的降级方案，配合使用
- **S10 ↔ 16-distill-archive**：产出 skill 必建 CHANGELOG.md（日期+版本+改动明细+验证状态），每次修改追加

## 七、S10 · 临床剂量补齐工作流（V4.4b 新增·nihaixia 2026-08-14 实战）

> S7 勘误只纠错，**补齐才闭环**。勘误完成后仍有大量方"临床剂量缺失"（nihaixia 实战：249 方中 130 方临床缺药），执行本流程。

### Step 1：缺药三分类

| 类 | 定义 | nihaixia 实例 |
|---|---|---|
| A | 临床只列关键药、缺"生姜两片/大枣十二枚"等**常例**（人物讲课习惯省略） | 葛根汤/桂枝汤临床行缺姜枣（8方） |
| B | 临床只给部分药味（缺 1-2 味非姜枣） | 桔梗汤只给桔梗、黄连阿胶汤缺鸡子黄（23方） |
| C | 完全无临床剂量记录（人物只讲辨证/用法） | 四逆散/酸枣仁汤/麦门冬汤等（99方） |

### Step 2：临床行生成——逐味独立判定（核心原则：临床行永不省略）

**每一味药独立取值，不整方打包**：
1. 该药有源文件/库内口述剂量 → 用口述（标〔口述〕）
2. 该药无口述 → 按「古方一两=临床一钱」换算（标〔换算〕）
3. 非"两"单位（枚/升/个/斤/合）→ 查 S9b 实物单位换算表；仍无 → 保留原单位标"按原方"
4. 原书方阙无原方可依（如杏子汤）→ 写人物推断或省略（唯一例外）

**标注纪律**：口述/换算/按原方必须显式标注，换算量不冒认人物亲口剂量。

### Step 3：产出临床剂量速查表

- 新建 `references/distilled/0X-clinical-dose-quickref.md`，格式：方名 | 原方（源文件） | 临床行（逐味） | 依据
- 覆盖分类：A/B 类 + 原方缺 + 未收录 → 一张表；C 类全量摸查 → 另一张表
- 无口述的 C 类方也要全量摸查源文件（**可能其实有口述**——nihaixia 实战 96 方中约 40 方摸查发现口述，如小建中汤"桂枝3钱白芍6钱"、黄连汤"统统等量"）

### Step 4：全库复查闭环

1. 提取全部"XX方"标题（脚本精确匹配 `^#{1,6}\s*\*{0,2}方名方` 模式，**勿用宽松正则混入口语噪声**）
2. 对比速查表覆盖 → 差集逐一核验上下文剂量词（钱/两/克/等分/等量/枚/升/方寸匕/比例）
3. 补漏（nihaixia 实战：206 标题中补 6 方：奔豚汤/天雄散/紫参汤/禹余粮丸/苓桂甘枣汤/消肿溃坚汤）
4. 特殊标注：人物明言"未用过"的方（侯氏黑散/鳖甲煎丸/薯蓣丸）标按原方比例；源文件确实未讲的方（三物黄芩汤）如实标注不硬编

### Step 5：写回与验证

- 速查表写入产出 skill 的 references/distilled/，SKILL.md 索引登记
- 输出规则同步（nihaixia 14c 卡片规范：临床行永不省略 + 逐味判定 + 查询顺序 05→06→即时生成）
- 每处修改三连：file_edit → grep 验证 → 注册 → 注册后复查
