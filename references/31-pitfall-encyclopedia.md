# 坑位百科（按发生阶段分组）

> 合并自胡希恕实战 + 黄元御实战 + nihaixia 索引事故，共 18 坑。
> 本文件从 SKILL.md 下沉（V4.5c·P1 瘦身），SKILL.md 仅在错误处理章留一行索引。

### A. 入口与素材阶段（4 坑）

| 坑 | 现象 | 解决方法 |
|----|------|---------|
| **原文素材与蒸馏本混淆** | 二手蒸馏本缺乏原文直接引用 | 优先用原著全文，蒸馏本作为参考对照 |
| **OCR 文件过大** | 3.5MB 文件分析不完整 | 先定位关键章节（总目录→行号），针对性读取 |
| **OCR 格式噪音** | 孤立页码/书眉页脚/LaTeX 残留/乱码/空行冗余 | 多轮清理脚本；HTML 表格与标题必须保留 |
| **古籍内容违规 411006** | 古籍敏感词触发注册拒绝 | 导入前 grep 排查，温和化替换 |

### B. 调研与合成阶段（7 坑）

| 坑 | 现象 | 解决方法 |
|----|------|---------|
| **YAML 缺失** | 411003（frontmatter 缺失或格式错误） | 必须加 YAML frontmatter |
| **子 Agent 压缩过度** | 产出 ~50KB 被压到 12KB | 不要压缩，保留完整产出 |
| **sub-agent 产出未落盘** | research 类型只读不改 | 主 Agent 必须主动 file_write |
| **无 modules/** | 缺乏原文检索能力 | 完整讲稿复制到 modules/ |
| **SKILL.md 过短** | 显著低于同复杂度医家 skill 行数 | 按 15 维度覆盖率补齐 |
| **SKILL.md 被追加超长** | 盲目追加超过 5000 行难维护 | 按差距优先级分批增量 |
| **引用死链** | 文件名与实际不符 | 全量体检 grep 核对 |
| **行号引用失效（V3.6 新增·nihaixia 实测）** | SKILL.md 写"详见第357-396行"/"L4868"，文件更新后行号错位（实测 L4868 实际内容在 4965 行） | 检索索引禁写行号，一律 `文件 搜"关键词"`；行号只留在独立 INDEX 文件且由脚本校验 |
| **子代理漏查部分 modules（V4.4b 新增·nihaixia 实测）** | 核查子代理只查了部分模块就判"未收录"（桂枝加龙骨牡蛎汤实际在 modules/05:759 有完整 7 味+临床口述，子代理仅查 modules/07 的"汤意"一句误报未收录） | 子代理任务书必须写明"遍历全部 modules/*.md"；主代理对"未收录/缺失"结论必须 grep 全库复核后再采信 |
| **OCR 异写漏检（V4.4b 新增·nihaixia 实测）** | 预筛脚本精确匹配漏掉异写：黄耆=黄芪、橘枳生姜=橘枳姜、䗪虫=蛰虫、连轺=连翘、苓桂术甘=茯苓桂枝白术甘草 | 预筛 MISSING 名单必须二次异写复查（同义词/近形字/简繁/省字），确认真缺才标未收录 |
| **中文文件名（V4.4c 新增·规范强制）** | 产出文件用中文/下划线/大写/空格命名（`01-伤寒论.md`、`01_xxx.md`），脚本路径处理与跨平台兼容出问题，且与 kebab-case 规范不一致 | 文件名一律 `NN-english-kebab-name.ext`（英文小写+连字符），中文只允许出现在文件内容里；SKILL.md 索引引用与实际文件名逐字一致 |

### C. 验证与发布阶段（6 坑）

| 坑 | 现象 | 解决方法 |
|----|------|---------|
| **缺乏对标基准** | 不知道优化到什么程度够 | 使用 15 维度覆盖率（达标≥9/15，优秀≥12/15，标杆≥14/15）；nihaixia 仅作方向参考（已非唯一基准） |
| **古今病名不互通** | "糖尿病"提问 AI 不知道"消渴" | 构建现代→古代病名映射 |
| **AI 回答无原文风味** | 回答用现代语言而非该医家口吻 | 强制原文引用+三段式模板 |
| **缺饮食** | 完整度下降 | Phase 4 补充（剂量已由 Agent 10 前置） |
| **每次改完不重注** | 用户拿到旧版 | 改完立即 ima_skill_create |
| **未注册文件被回滚（血泪）** | 本地文件全部丢失（含 CHANGELOG 同日多版本漏记：nihaixia 15 实测 v15c 记录消失） | **注册三步防护（V4.5 升级）：①注册前把完整目录 zip 备份到 /sandbox/workspace/（唯一持久位置）②注册后立即 grep 关键改动点验证未被平台快照覆盖③被覆盖则从备份恢复重放；CHANGELOG 每次注册前检查当日条目是否已记录（含同日多次修改）** |
| **file_edit 吞标题（V4.4b 新增·nihaixia 实测）** | old_string 含"## 三、XX"标题行时，替换后该标题被连带删除，文件章节编号错乱 | 替换锚点避开标题行本身（用行尾文本作锚）；编辑后 grep 章节标题清单验证无丢失 |
| **CHANGELOG 同日多次修改不同步（V4.4b 新增·nihaixia 实测）** | 同一天早上/下午多次大改，CHANGELOG 只记了早上的条目，下午改动全部漏记 | 每次注册前检查 CHANGELOG 是否已记录本次改动；同日多次修改合并为"vX.Yb 当日补记"或分条目 |
