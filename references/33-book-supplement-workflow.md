# 33 · 书籍补遗工作流（S14b 新增·2026-08-23 李可八书实战提炼）

> **定位**：用户提供某人物/主题的**新书 OCR**，要求"看看 skill 有没有、优化进去"时的标准流程。
> **来源**：2026-08-23 李可 skill 连续处理 8 本 OCR 书籍（经验专辑/医论/处方集/六经辨证学/抄方记/阳气对话/基础有效量/类方批注）实测沉淀。
> **核心思想**：先查覆盖再补录——避免重复蒸馏已覆盖内容，只补真正缺失的增量。

---

## 一、流程总览（5 步）

```
① 摸底 → ② 覆盖检查 → ③ 缺口判定 → ④ 补遗蒸馏 → ⑤ 集成与验证
```

## 二、步骤详解

### ① 摸底（源文件）

- `wc -l` + `du -h` 看体量；`grep -n "^# \|^## "` 看章节结构（OCR 标题行=章节地图）
- 判断书籍类型：**医案集**（补 cases/）/ **医论/访谈**（补 modules/ 或表达素材）/ **批注版**（补批注）/ **方剂索引**（补速查表）

### ② 覆盖检查（核心·防重复劳动）

**方法**：提取书的**标志性内容**（方剂名/专病名/章节标题/独有概念），逐个 `grep -rl` 到目标 skill 的 modules/cases/references：

```bash
for kw in "标志方剂1" "标志方剂2" "专病名" "独有概念"; do
  cnt=$(grep -rl "$kw" skill_dir/modules/ skill_dir/cases/ | wc -l)
  echo "$kw: $cnt"   # 0=缺失 1-2=可能提及 3+=已覆盖
done
```

**判定**：
- `0 命中` → **真缺失**，补录
- `1-2 命中` → 抽查命中处是"完整内容"还是"仅提及"（编按/一句话）——提及则补详
- `3+ 命中` → 已覆盖，不补
- **陷阱**：书名可能早列在 README 蒸馏来源表但**实际知识库未收录**（李可实战：README 列 11 著作，实际 5 本内容缺失）——以**知识库实际内容**为准，不信 README 声明

### ③ 缺口判定

| 书类型 | 缺口形态 | 补遗落点 |
|--------|---------|---------|
| 医案集 | 独有医案/处方细节 | cases/0N-*.md |
| 医论/访谈 | 独有观点/口语原话 | modules/0N-*.md |
| 批注版 | 批注原文/学术观点 | modules/0N-*.md |
| 方剂索引 | 方剂全景一览 | modules/0N-fangji-suoyin.md |
| 年谱/生平 | 时间线细节 | modules 或 SKILL.md 时间线 |

### ④ 补遗蒸馏

- 按"病证/论点 + 病机/核心观点 + 方药完整剂量 + 煎服法 + 医案要点 + 鉴别/禁忌"结构
- **剂量必从原文核对**（禁编造；OCR 不清标注"存疑待核"不硬编）
- 文件头注明：来源（书名/主编/版本）+ 用途（与哪些已有文件互补）
- 目标行数：模块 100-300 行（访谈实录可长至 1900 行，价值优先）
- **OCR 甄别**：错字按上下文还原并注记（李可实战：制川草乌→制川乌/制草乌、菟丝于→菟丝子）；保留专业字（癥瘕/穭豆/瞤）

### ⑤ 集成与验证

- **SKILL.md 索引集成**：新文件必入索引表（病种行+路由），用 Python 插入（注意文件行尾 CRLF/LF）
- **编码**：新文件 zhconv 转简体 + 0 乱码（32 号文件七节）
- **文件名**：英文 kebab-case（V4.4c）
- **敏感词预扫描**（见坑位）：政治/性/暴力词 → 注册前温和化
- **验证**：grep 章节数/方名数、死链复查、注册后防覆盖复查

---

## 三、批量书籍处理（多本书并行）

- 每本书 spawn 1 个 heavy 子 agent（独立任务：覆盖检查→补遗→集成→编码→验证）
- 并行上限 3 个/批（李可实战：3+2 两批），避免资源错误
- 每 agent 交付标准明确：产出文件路径/章节数/索引行/SKILL.md 集成方式

## 五、坑位

1. **README 声明 ≠ 实际收录**：蒸馏来源表列了书不代表知识库有内容——覆盖检查必须查知识库实际文件
2. **子 agent 只验字符串不验路径**：集成时 `06_benshu-buyi.md` vs `06-benshu-buyi.md` 死链——验收必须"引用路径与文件名逐字符匹配"
3. **OCR 敏感词**：补遗文件含"毛主席/早泄/自杀"等触发 411006——B3 产出后注册前必跑敏感词扫描
4. **大文件体积**：访谈实录可达 160KB+（modules/10）——注意 skill 总容量（32MB 上限，1.4MB 的李可无虞）
5. **同文件并行编辑丢修改**：多 agent 改同一 SKILL.md 必须串行或 Python 行级插入
