# cases/ 医案库构建规范

> V2.3 新增。对标倪海厦 skill（nihaixia）的 6 个疾病分类案例库（癌症147案/心血管22案/代谢12案/免疫2案/神经3案/其他59案）。
> 用途：蒸馏出医案后，如何分类、如何写"证-机-方-效"完整链条、如何建检索索引。

## 分类规则

按疾病系统分类，每类一个文件，命名 `NN_类别.md`：

| 分类 | 命名 | 示例 |
|------|------|------|
| 癌症/肿瘤 | 01_cancer.md | 肝癌/乳癌/肺癌/脑瘤/血癌… |
| 心血管 | 02_cardiovascular.md | 心梗/胸痹/心衰/高血压… |
| 代谢/内分泌 | 03_metabolic.md | 糖尿病/痛风/肥胖… |
| 自身免疫 | 04_autoimmune.md | 红斑狼疮/类风湿… |
| 神经/精神 | 05_neurological.md | 癫痫/失眠/中风后遗… |
| 其他 | 06_other.md | 未归类杂病 |

> 分类数量按实际医案覆盖调整，无此类则省略。每类开头写"共 N 个医案，包含：…"。

## 单案格式：证-机-方-效 四段链

每个医案必须含完整四段链（缺一不可）：

```markdown
### {日期}{病名}（{编号}）
- **证**：{辨证结果：六经/八纲/脏腑定位}
- **机**：{病机分析：为什么是这个证}
- **方**：{处方：方名+组成+剂量+煎服法}
- **效**：{疗效：症状变化/指标变化/疗程}
- **来源**：{出处：讲稿/医案集/页码}
```

**要求**：
- 证、机、方、效必须**全部来自原文**，禁止补充未记载的推理
- 疗效缺记录时写"未见疗效记录"，不得编造
- 剂量按原文记录（如"三钱"），不做换算，除非原文有明确换算

## 检索索引

cases/ 目录内建一个索引文件 `00_index.md`：

```markdown
# 医案库索引

| 疾病/症状 | 文件 | 相关医案 |
|-----------|------|---------|
| 肝癌 | 01_cancer.md | 050330、050402… |
| 胸痹 | 02_cardiovascular.md | 050423… |
| 糖尿病 | 03_metabolic.md | 050405… |

> 检索方法：用户报病名/症状 → 查本表定位文件 → Read 对应医案
```

## SKILL.md 集成

在 SKILL.md 中写"医案参考"路由（对标 nihaixia 的加载规则）：

```markdown
- 医案参考 → 按疾病类型加载 cases/ 目录：
  - 癌症 → cases/01_cancer.md
  - 心血管 → cases/02_cardiovascular.md
  - 代谢病 → cases/03_metabolic.md
  - …
  - 综合医案 → modules/03_yian.md（如有完整版）
```

## 数量要求

| 场景 | 最低标准 |
|------|---------|
| 新蒸馏（有医案素材） | ≥ 5 则完整医案（证-机-方-效链） |
| 优化已有（有完整医案集） | ≥ 30 则 或 按疾病分类全量收录 |
| 无医案素材 | 不强制，但需在"已知差距清单"标注 |
