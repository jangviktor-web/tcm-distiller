# 25 · 索引完整性审计规范（V3.6 新增）

> **来源**：nihaixia SKILL.md 索引 44 条审计实战（2026-08-12）。该次审计发现：24 条索引缺跨模块引用、18 条完全缺失主题、2 条结构性遗漏（文件未入表、篇章有内容无索引）。
> **适用**：蒸馏产物 SKILL.md 的关键词索引区（Phase 2 必含项 #2）+ 原文 INDEX 文件。
> **配套脚本**：`scripts/validate_keyword_refs.py`（关键词有效性批量验证）。
> **部署说明**：验证脚本随蒸馏产物复制一份（`cp 框架/scripts/validate_keyword_refs.py 产物/scripts/`），使产物自包含可验证；也可从框架侧以绝对路径执行（`python3 /root/.skills/中医思维蒸馏器/scripts/validate_keyword_refs.py --skill 产物/SKILL.md`）。

---

## 一、索引引用格式铁律

1. SKILL.md 检索索引的"搜索位置"一律用 **`文件 搜"关键词"`** 格式（`modules/04_jingui.md 搜"黄疸"`）。
2. **禁止**在 SKILL.md 正文直写行号（`详见第357-396行` / `L4868` / `约1009行`）——行号在文件更新后必然错位。
   - 实测案例：nihaixia SKILL.md 中 `L4868` 指向"判断瘀血的方法"，文件更新后实际内容在 4965 行；`第357-396行`（桂枝汤方义）同样错位。
3. 行号仅允许存在于**独立 INDEX 文件**（`modules/00_index.md`、原文数字化篇目导航），且必须由脚本自动生成/校验（`scripts/validate_index.py`、`scripts/gen_index.py`），禁止手工 hardcode。
4. 例外豁免：原文模块内部（modules/XX.md 自身正文）讨论条文号（如"第176条"）属于**条文号**，非行号，允许保留。

## 二、关键词有效性批量验证（必跑）

```bash
python3 scripts/validate_keyword_refs.py --skill SKILL.md
```

- 解析全部 `文件 搜"关键词"` 引用 → 验证关键词真实存在于目标文件 → 输出失效清单（行号/文件/关键词/原因）
- 可选参数：`--count-lines`（按行计数口径）、`--min-hits 5 --max-hits 400`（命中量阈值检查）
- **通过标准：失效 = 0**；有失效立即修复（改关键词或删引用），禁止带着死引用注册
- 验证口径说明：关键词计数按"行 grep"（`grep -c`），非子串计数——两者结果可能差异大（如"西医"按子串 1341 次、按行 534 行），审计以按行口径为准
- **局限提醒**：脚本只能发现"0 命中"（死引用），无法识别"语义误匹配"（关键词存在但语境不同，如 nihaixia modules/07 的"肝1"实为"切除左肝1/8"比例而非穴位）——高危条目需人工抽查上下文

## 三、完整性三检（反向审计）

> 死链检查（S4 #1）只覆盖"引用→文件"正向方向，以下三类是**反向审计**，检查"有内容但没被索引到"。

### 检① 跨模块引用缺失（现有条目缺来源）

**方法**：对每个已有索引主题，列出"该主题内容分布在哪些文件"，与索引实际引用比对。

```bash
# 对主题关键词，统计各候选文件的命中行数
for f in modules/*.md; do echo "$f: $(grep -c '主题词' $f)"; done
```

**判定**：命中 ≥5 行且索引未指向 → 补充引用。优先补命中最多的前 2-3 个文件，避免引用爆炸。

### 检② 完全缺失主题（有实质内容但无条目）

**方法**：主题清单 vs 索引表反向比对。

1. 从 modules/ 提取高频主题词（症状/方剂/理论）：`grep -ohE "候选词" modules/*.md | sort | uniq -c | sort -rn`
2. 与 SKILL.md 索引表逐条比对，找出"文件里大量出现但索引无条目"的主题
3. 判定是否值得新增：命中 ≥5 行 + 有临床/理论价值 + 用户可能问 → 新增索引行

**示例**（nihaixia 实战新增的 12 条）：甲状腺/甲亢（modules/09 搜"瘿"8处 + modules/03 搜"甲状腺"29行）、尿毒症（modules/07 搜"尿毒症"10行）、渐冻症、小儿/育儿、麝香矾石散、腹膜透析、针灸治症、面相望诊、经方剂量、手抖/SLE、经方妙用讲座、五行饮食观。

### 检③ 结构性遗漏（文件未入索引表）

**方法**：`ls` 实际文件 vs 索引表反向比对。

```bash
# 列出所有实际文件
ls modules/*.md cases/*.md references/*.md 2>/dev/null | sort
# 与索引表/路由表提及的文件比对，找出"存在但从未被索引"的文件
```

**示例**（nihaixia 实战）：`cases/04_autoimmune.md`（2 个自身免疫医案）存在于磁盘，但医案库索引表完全没提——死链检查查不出此方向，只有反向比对能发现。修复：索引表补一行 `| 类风湿/帕金森/自身免疫 | cases/04_autoimmune.md |`。

**同类场景**：modules/ 内容非自然序（如金匮篇目跳跃分布）时，需建立"篇章导航表"（篇目→文件→行号）并在关键词索引为每篇补一行（nihaixia 金匮 6 篇补录）。

## 四、关键词选择原则

| 原则 | 阈值/规则 | 示例 |
|------|----------|------|
| 最小命中门槛 | 按行命中 <5 不单独建索引 | "情志"在 modules/03 仅 1 行 → 放弃该引用 |
| 噪音上限 | 按行命中 >400 属噪音，无定位价值 | "西医"在 modules/03 达 534 行 → 不索引（搜了等于没搜） |
| 聚焦词替代 | 用高命中且聚焦的词，弃泛词 | "月经"84 行 vs "妇人"6 行 → 选"月经"；"类风湿"0 行 vs "风湿"27 行 → 选"风湿" |
| 命中为空即废 | 关键词在目标文件 0 命中 → 删除或改词 | "腹满寒疝"仅 3 行 → 改搜"腹满"66 行或"寒疝"21 行 |
| 引用数量控制 | 单条目 ≤3-4 个来源 | 来源过多时按命中量取前 3，其余并入"说明"列 |

## 五、审计触发时机

| 时机 | 动作 |
|------|------|
| Phase 3 质量验证 | 索引健康检查三必检（行号残留/关键词失效/完整性三检） |
| Phase B5 必检表 | 索引健康检查行（validate_keyword_refs.py 失效=0 + 无行号残留 + 三检通过） |
| S4 知识网络体检 | 检查项 6（关键词验证）+ 检查项 7（完整性三检） |
| Pipeline B 每次增量后 | 跑 validate_keyword_refs.py + 完整性三检，0 失效再注册 |
| 源文件（modules/）更新后 | 重新生成 INDEX（gen_index.py）+ 重跑全部验证 |
