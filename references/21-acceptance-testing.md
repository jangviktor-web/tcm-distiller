# 蒸馏产物验收测试方法论（B级沉淀·源自黄元御V2.9实战）

> 适用：蒸馏产物（skill）完成后的质量验收。包含两部分：①互联网热度实测（验证 skill 能否回答真实用户高频问题）②负优化审计（验证优化改动未降低质量）。源自黄元御 skill 的 50 条热门问题实测 + 达尔文棘轮审计实战（2026-08-04）。
> **V4.0 补充**：验收测试中的剂量类题目，答案基准以 **S7 剂量勘误结果**为准（references/26），而非 Agent 10 提取稿或通行本——防止用通行本衡量源文件版剂量（实战 7 处 judge 误判教训）。

## 一、热门问题实测法（B1）

### 为什么需要
- 蒸馏者自测（"我觉得挺好"）≠ 真实用户可答（"我问的问题有答案吗"）
- 互联网热度反映真实需求：用户最常问什么，skill 就该能答什么

### 流程（四步）

**步骤 1：热度问题研究**（子 agent 独立完成）
- 搜索方向覆盖：热门病种症状（失眠/湿气/脱发/结节…）、养生话题（三伏贴/艾灸/泡脚…）、体质概念（阳虚/阴虚/肝郁…）、争议话题（中药毒性/中医vs西医…）、高频求医话术（"怎么调理/能根治吗/看中医还是西医"）
- 产出 50 条：具体可答型问题（非开放讨论），分 ≥6 类，标注热度（高/中/低）+ 来源（搜索趋势/常见问诊/养生媒体）

**步骤 2：支撑度实测**（子 agent 独立执行）
- 对每条问题：①判断该体系辨证方向 ②在 skill 中检索支撑（索引/方证/篇目/references）③评级：
  - ✅ 直接可答（找到明确辨证+方药支撑）
  - 🟡 部分可答（有理论缺方药，或多文件组合）
  - ❌ 不可答（skill 无相关支撑）

**步骤 3：修复分类**（关键——把缺口分类处理）
| 缺口类型 | 判断 | 处理 |
|---------|------|------|
| **整理遗漏** | 原文有，skill 索引/映射漏了 | 🔴 必须修（补索引/词条/映射锚点）——如黄元御"头痛根原"错误引用（该篇目不存在）、06 索引缺"项强/眩晕"词条 |
| **体系天然边界** | 该中医师体系本身没有 | 🟢 诚实边界声明，不硬编（如外治法/现代药学） |
| **推演类** | 体系理论可推演但无原文直述 | 🟡 标注"推演"，加原文旁证锚点 |

**步骤 4：补强与复测**
- 按分类修复后，补测原 ❌/🟡 条目，确认提升
- 黄元御实战：直接可答率 58% → 95%+

### 验收标准参考
- 综合可答率（✅+🟡）≥ 80% 可交付；✅ ≥ 60% 为良好
- ❌ 条目必须全部有"诚实边界应答路径"（不硬编）

### 高频易错辨证点（实测重点考察）
实火/虚火、寒湿/湿热、阴虚/阳虚、肾阴虚/肾阳虚、脾虚/湿气、上热下寒——这些是用户最容易问、也最容易答错的点，实测时应专门覆盖。

## 二、负优化审计（B2·达尔文棘轮）

### 为什么需要
优化 skill 时（精简/瘦身/重构），可能"看着更小更干净，实际丢了核心功能"——负优化。必须用**独立子 agent** 审计（避免自己改自己评）。

### 流程

**步骤 1：优化前存档**
- 任何优化前，先把当前 SKILL.md 完整版存为 `references/full-body.md`（备份点）

**步骤 2：独立对比审计**（子 agent 执行）
- 逐章对比：优化前（full-body）vs 优化后（SKILL.md）
- 输出信息丢失清单：每条 = 丢失内容 + 影响等级
  - 🔴 严重（核心功能退化：辨证/开方/角色扮演铁律受损）
  - 🟡 中等（回答质量下降但可恢复）
  - 🟢 轻微（仅少些参考信息）
- 关键检查：角色扮演"必引原文"铁律是否受损（公式原文被砍后 AI 引什么？索引锚点能否替代？）

**步骤 3：棘轮回滚**
- 🔴/🟡 级丢失 → 回滚恢复原文
- 🟢 级且 references 有兜底 → 保留
- 黄元御实战：回滚 4 处（公式 11/12/14 完整原文、表达风格"尊崇四圣"），保留全部正优化（快速路由/行号修正/合理精简）

**步骤 4：注册后验证**
- 修改完成 → ima_skill_create 注册 → **立即 grep 验证关键内容仍在**（沙箱存在文件回滚现象，部分修改会丢失需重补）

### 铁律
1. **优化前后对比必须逐字 diff**（README 声称的功能不可信，以实际文件为准——黄元御实战下载 GitHub 仓库 md5 对比 65 文件）
2. **同一文件的多处修改必须串行 file_edit**（并行存在写入竞争，部分修改静默丢失）
3. 每次修改后立即 grep/校验验证生效，再继续下一步

## 三、跨流派对话测试法（V4.0 新增·源自吴鞠通 V3.1 实测）

**目的**：验证蒸馏产出的"心智模型内核"是否立得住——两个流派 skill 对**同一病案**作答，暴露病因观/治则的根本分歧。

**流程**：
1. 选典型病案（如"盛夏发热 39.2°C、微恶风寒、咽痛口渴、脉浮数"——寒伤阳 vs 温伤阴的试金石）
2. 两个 skill 独立作答（各自遵循本流派辨证框架）
3. 对比核心分歧点（吴鞠通 V3.1 实测：倪驱邪优先"汗是排邪通道" vs 吴存津优先"汗为心液误汗伤阴"——本质是寒伤阳 vs 温伤阴的病因观差异）
4. 验证分歧是否可追溯到各自源文件原文（不可追溯=蒸馏失真）

**产出**：跨流派对比报告 + 可选 README"流派对比"章节（吴鞠通 README 已有经方派 vs 温病派 10 维对比范例）。

## 四、语气量化评估法（V4.0 新增·源自倪海厦 50 题语气测试）

**目的**：量化验证表达 DNA 还原度（模板化/舞台指示/互动感）。

**指标**（两版作答对比计数）：
| 指标 | 说明 | 倪海厦实测 |
|---|---|---|
| 互动追问 | 反问/追问病人的次数 | 23→68 处（修复后） |
| 模板结尾 | "请注意/记住"式说教结尾 | 27→1 |
| 舞台指示 | "（微笑）（停顿）"类描述 | 清零 |
| 口头禅频次 | "嚎"等标志词使用 | 3句≤1/50字段≤2 |

**流程**：50 题 → 新旧两版各 4 组子 agent 作答 → judge 盲评 → 计数对比 → 修复（去模板化/回补经典段子/口头禅场景固化）。

## 五、A/B 双版本盲评法 + 长答还原度测试（V4.3 新增·源自倪海厦 20 题长答实战）

**用途**：棘轮优化的标准实证——"新版是否负优化/是否更像本人"不能靠感觉，必须新旧双版本盲评。

**A/B 双版本盲评法**：
1. 准备旧版（v2.3.0 原版备份包解压到独立目录）
2. 3 题库并行：短答语气（50 题）/ 长答辨证（20 题）/ 领域专项（如剂量 30 题）
3. 作答：分片 × 双版本（每片 1 作答 agent 答两版，标记 new/old 不互参考）
4. judge 盲评：标记 A/B 打乱，只凭质量打分（**领域专项题基准=源文件/勘误表，禁止用通行本衡量人物版**——7 处误判教训）
5. 棘轮决策：新版总分 ≥ 旧版 + 专项 ≥90% → 可推送；局部倒退（单题组 -0.1）→ 定位修复 → 复测该题组

**长答还原度测试**（详见 references/28-expression-verification.md）：
- 20 题完整诊疗问诊，双版本作答，4 维盲评（口语化/人物味道/故事感/总体像本人）
- 倪师实测：短答新版全胜但长答 11-20 十题全败（规整模板）→ 修复 6 大差距（问诊互动/故事/调侃/批判强度/口头禅/冗余）→ 复测 9 胜 1 平 0 败
- **验证还原度必须长短结合**：短答测口头禅，长答测质地
