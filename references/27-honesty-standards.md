# 27 · 诚实标注规范（S10，质量铁律）

> 来源：倪海厦 skill 剂量勘误实战教训（2026-08-13）。核心：**宁可显性标注缺口，不可编造填补**。
> 适用：蒸馏产出的所有 skill（方剂剂量/穴位定位/条文原文/临床经验均适用）。

## 一、五类必标场景

| 场景 | 标注方式 | 实战案例 |
|---|---|---|
| **无法核对**（源文件确无内容） | 标注"源文件未涉及/无方行"，按通行本补时注明"按通行本补" | 牡蛎泽泻散（源文件无条文无方行）；崔氏八味丸（附方倪师未讲） |
| **来源边界** | 注明"源文件有方行（行号）"或"源文件仅提及名称，未讲定位主治" | 三黄穴（源文件仅伤寒3395 提及名称）——定位主治标"待补一手资料，不得编造" |
| **转录矛盾**（源文件自身矛盾） | 如实标注，不改原文 | 赤小豆当归散"当归十两(30g)"（十两≠30g）；麻黄加术汤两处麻黄量不一；苦酒汤鸡子"十枚" |
| **知识缺口** | 显性化：建"待补条目"（位置占位+已知信息+缺什么），不隐藏 | 三黄穴待补条目 |
| **源文件口误** | 忠实转录 + 必要时加"【源文件口误】"注；用户确认后可修正语义 | "三黄三黄汤"→用户确认后改"三黄泻心汤"（modules 层改，源文件不动） |

## 二、AI 检索防错原则

1. **回答时区分"源文件有据"与"通行本/通识补充"**——混用会误导用户与测试 judge
2. 引用剂量必须注明版本来源（"讲课版"或"通行本"）+ 换算体系（①考古/②台湾/③直换）
3. 无法核实的细节说"源文件未覆盖"，不推测
4. 知识缺口以"待补条目"形式保留在 skill 中（显性化而非删除），后续有一手资料即补

## 二点五、不编造 ≠ 不缺失（V4.0 新增·麻黄附子细辛汤教训）

- 90 题测试教训：某方因"不编造策略过度"导致**缺组成留空**（麻黄附子细辛汤"缺组成"被判错）——诚实标注不等于留白
- **平衡原则**：源文件有方行→照录；源文件无方行但有条文/讲解→按通行本补+标注"按通行本补"；两者皆无→标"未涉及"+待补条目。**三档必有一档，不允许静默缺失**
- 方剂条目必须含：组成+剂量（至少一档来源）+出处/主治；缺任何一项即"不完整"需补

## 三、子 Agent 复核纪律（防误报）

二次检测/审计的子 agent 必须：
1. **以源文件原文逐字为准**——不得凭通行本/记忆判断
2. 报告"无方行"前先穷尽搜索（异名/异字/拆行）——本会话 17 处"无法核对"实为漏检
3. 剂量数字必须附源文件行号+原文摘录（可回溯）
4. 主 agent 对子 agent 结论抽查复核（本会话教训：子 agent 2 次误报剂量、2 次误报方行缺失，均以源文件核验纠正）

## 四、注册防回滚（平台快照覆盖风险）

- 修改→grep 验证→注册→**注册后立即复查关键修改点**（本会话经验：平台注册可能用旧快照覆盖本地，文件 mtime 回退）
- 大修改前先备份完整目录到 /sandbox/workspace/（唯一持久位置）
- 被覆盖则从备份恢复重放
