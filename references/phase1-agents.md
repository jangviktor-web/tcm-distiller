# Phase 1：9个并行子Agent任务模板

> 直接复制到 subagent_spawn 的 task 参数中使用。把 `{name}`、`{source_path}` 替换为实际值。

**模型档定义**：
- **heavy**：深度推理任务（心智模型/决策启发式），需要最大上下文+强推理能力
- **light**：描述性提取（表达 DNA/反模式/生平/张力/谱系/FAQ/安全层），标准上下文即可

**Agent ↔ 维度映射**（9 个 Agent 对应 14 个标准维度中的 9 个，其余 5 个维度由 Phase 2 框架合成时整合）：

| Agent | 提取维度 | 模型 |
|------|---------|:---:|
| Agent 1 | 维度 1 · 核心心智模型 | heavy |
| Agent 2 | 维度 2 · 临床决策启发式（含维度 10 方证体系、第 9 条分域取法） | heavy |
| Agent 3 | 维度 3 · 表达 DNA | light |
| Agent 4 | 维度 4 · 反模式与诚实边界（含维度 5 诚实边界 6 层） | light |
| Agent 5 | 维度 9 · 生平与传承（含来源分级） | light |
| Agent 6 | 维度 11 · 内在张力 | light |
| Agent 7 | 维度 12 · 智识谱系 | light |
| Agent 8 | 维度 13 · 常见问题速查 FAQ | light |
| Agent 9 | 维度 14 · 临床安全层（含用药铁律） | light |

> 维度 6 剂量思维、维度 7 饮食调理、维度 8 条辨框架、维度 15 功法体系（可选）由 Phase 2/4 增量补充时整合，不属于 9 维并行调研范围。

## Agent 1：核心心智模型（用 heavy 模型）

```
分析{name}的讲稿/著作，提取核心心智模型。

源文件：{source_path}

提取内容：
1. 他看病的根本框架（如六经八纲、卫气营血、脏腑经络…）
2. 辨证论治的核心原则
3. 反复出现≥3次的核心理念（真信念）
4. 他对经典的根本态度
5. 他的第一性原理（最底层不证自明的原则）

输出到：/sandbox/workspace/skills/{skill_name}/references/01-core-philosophy.md

格式：每个心智模型含"一句话定义+详细阐述+原文支撑+临床体现"
区分"他说的"vs"后人总结的"
发现矛盾保留矛盾，不和稀泥
```

## Agent 2：临床决策启发式（用 heavy 模型）

```
分析{name}的讲稿/著作，提取临床决策启发式。

源文件：{source_path}

提取内容：
1. 辨阴阳的快捷方式
2. 选方的第一刀规则
3. 加减用药口诀/规律
4. 类似方证鉴别维度
5. 预后判断标志
6. 死证标志
7. 欲愈标志
8. 分域取法规则表：若该医家为集成型/多源头人物（如"外感法张仲景、内伤法李东垣、热病用刘河间、杂病用朱丹溪"，或跨经典内化），输出"病域→取法来源→代表方剂"三列规则表，标明每个病域该用哪家体系、何时切换

输出到：/sandbox/workspace/skills/{skill_name}/references/02-decision-heuristics.md

格式：每条规则含"规则+原文支撑+临床应用场景+反例/边界"
备注具体的条文号
```

## Agent 3：表达DNA（用 light 模型）

```
分析{name}的讲稿/著作，提取表达风格。

源文件：{source_path}

提取内容：
1. 术语翻译实例（文言→大白话）
2. 口头禅和高频句式
3. 否定式表达（对哪些观点直言"这是错的"）
4. 教学技巧
5. 他信什么/不信什么的态度图谱

输出到：/sandbox/workspace/skills/{skill_name}/references/03-expression-dna.md
```

## Agent 4：反模式与边界（用 light 模型）

```
分析{name}的讲稿/著作，提取反模式和诚实边界。

源文件：{source_path}

提取内容：

反模式：
1. 禁治法列表（禁汗X条、禁下X条…）
2. 他反对的理论观点（如反对五行、反对《内经》解伤寒…）
3. 他认为有问题的方剂/条文
4. 他反对的临床做法
5. 流派边界防护（V3.3 新增·防跨流派误用）：
   - 该医家**不会做的事**（如问火神派用银翘散、经方派长篇舌诊）
   - 被误认的常见误解（用户把 A 流派逻辑套到 B 角色身上）
   - 此子节不需额外 agent，归入 Agent 4 产出 04-antipatterns-boundaries.md 末尾

诚实边界（V2.2升级为6层）：
1. ✅ 已验证信息：基于一手素材可确认的事实
2. ⚠️ 仍需验证：有来源但未交叉验证的内容
3. ❌ 不能做的事：技能边界（不能开处方/不能替代医疗建议）
4. ❌ 扮演时绝对禁止说/做的事：角色红线
5. ❌ 扮演时他会说"错！"的话：常见错误示范（成对出现）
6. ✅ 扮演时他会认可的话：正确示范（成对出现）

输出到：/sandbox/workspace/skills/{skill_name}/references/04-antipatterns-boundaries.md

每条配上原文支撑；第5、6层必须成对（错误示范+正确示范）
```

## Agent 5：生平与传承（用 light 模型）

```

提取内容：

2. 师承关系

```

## Agent 6：内在张力（用 heavy 模型）

```
分析{name}的讲稿/著作，提取内在张力。

源文件：{source_path}

提取内容（目标 3~6 组张力）：
1. 观点冲突：他同时坚持的两个对立观点（如"经典至上"vs"临床灵活"）
2. 理论vs实践落差：理论主张与临床实际做法的差异
3. 立场vs包容：激烈批评某派，但某些情境下又表现出包容
4. 理念vs现实：理想主张与现实处境的矛盾
5. 语气反差：批评时激烈 vs 教学时温和/幽默
6. 对同一问题的前后态度变化（如有）

每组张力格式：
## 张力N：{张力A} vs {张力B}
- A 面：{原文支撑}
- B 面：{原文支撑}
- 情境倾向：什么情况下倾向A / 什么情况下倾向B
- 打破平衡的瞬间：情绪化/特殊场景下如何失衡

输出到：/sandbox/workspace/skills/{skill_name}/references/06-tensions.md

要求：
- 张力必须有原文依据，禁止编造
- 发现矛盾保留矛盾，不和稀泥（与 Agent 1 的要求一致）
- 这是让角色"立体化"的关键维度，宁多勿少
```

## Agent 7：智识谱系（用 light 模型）

```
搜索并整理{name}的智识谱系（思想来源与定位）。

源文件：{source_path}（结合网络搜索补充）

提取内容：
1. 受谁影响（思想上游）：
   - 启蒙老师/师承关系
   - 核心经典（如伤寒论、内经、本草经）
   - 影响其思维的其他人物/流派
2. 影响谁（思想下游）：
   - 弟子/学生
   - 受其影响的流派或后学
3. 在思想地图上的位置：
   - 所属流派及立场
   - 与同时代/历史人物的关系（对立/相近）
   - 对西医/现代医学的态度

输出到：/sandbox/workspace/skills/{skill_name}/references/07-intellectual-lineage.md

格式：
## 智识谱系
### 受谁影响（思想上游）
- {人物/经典}：{关系+影响点}
### 影响谁（思想下游）
- {人物/群体}：{影响方式}
### 在思想地图上的位置
- 流派定位：{所属流派+立场}
- 对比坐标：{与谁对立/与谁相近}
- 现代医学态度：{立场}

信息源黑名单：不使用知乎、微信公众号、百度百科作为唯一来源
```

## Agent 8：常见问题速查 FAQ（用 light 模型）

```
分析{name}的讲稿/著作，提取常见问题速查表。

源文件：{source_path}

提取内容（5~15 个高频问题）：
1. 饮食养生类（如牛奶能不能喝/病后忌口）
2. 常见症状类（如失眠/便秘/出汗/感冒）
3. 核心理论类（如怎么判断病在哪经/什么叫某证）
4. 经典方剂类（如某方何时用/某药为何要炮制）

每个问题格式：
### Q: {高频问题}
{2~4 句直接回答}

要求：
- 每个回答必须基于讲稿原文，禁止编造
- 回答体现该医家的典型语气（配合 Agent 3 的表达DNA）
- 覆盖上述 4 类，宁缺毋滥（不确定的问题不写）

输出到：/sandbox/workspace/skills/{skill_name}/references/08-faq.md
```

## Agent 9：临床安全层（用 heavy 模型）

```
分析{name}的讲稿/著作，提取临床安全关键信息。

源文件：{source_path}

提取内容：
1. 误治急救方案：
   - 误汗/误下/误吐后的急救方剂
   - 救逆方列表（如甘草干姜汤/芍药甘草汤/调胃承气汤/四逆汤）
2. 传变预警：
   - 该医家辨证体系的传变规律（如六经传变）
   - 提示病情恶化/危重的证候标志
   - 死证/预后不良标志
3. 用药铁律：
   - 绝对禁忌（禁汗/禁下/配伍禁忌）
   - 剂量红线（最大量/超大剂量警告）
   - 反复强调的用药原则

输出到：/sandbox/workspace/skills/{skill_name}/references/09-clinical-safety.md

格式：
## 临床安全层
### 误治急救方案
- {误治场景} → {急救方/处理}
### 传变预警
- {传变规律}：{如何判断/预警标志}
### 用药铁律
- ❌ {禁忌}
- ⚠️ {剂量红线}
- ✅ {必须遵循的原则}

每条配原文出处；不确定的内容标注"未见原文，勿写"；急救内容必须附加"需执业医师确认"提示
```

## Agent 10：剂量思维（用 light 模型·V3.4 前置新增）

```
分析{name}的讲稿/著作，提取剂量思维（从 Phase 4 前置到 Phase 1，防初版无剂量）。

源文件：{source_path}

提取内容：
1. 换算标准（V4.0 按 S9 三体系）：①考古考证（1两≈15.6g，仅理解规模）②台湾临床（1钱=3.75g）③**临床直换铁律（古方一两=临床一钱）**——优先提取该医家本人度量衡论述原话（如倪师神农本草经"汉朝1两就是现在1钱"）标注出处；个人换算（如胡希恕一两≈三钱）归入③变体
2. 常用药实测剂量表（高频药+剂量范围）
3. 剂量红线（某药最大量/超大剂量警告）
4. 剂量调整规则（体质/津液/病情）
5. 药材选择偏好：产地/形态/炮制偏好（如江油附子、生附子），特殊药选用逻辑
6. 素材无剂量 → 明确标注"素材不足"，供 Phase 3 标记"可选缺"

输出到：/sandbox/workspace/skills/{skill_name}/references/12-dosage-framework.md

格式：剂量表 + 红线清单 + 药材偏好小节，每条附原文出处
```

```
1. 修炼总纲与次第（如炼精化气→炼气化神→炼神还虚）

输出到：/sandbox/workspace/skills/{skill_name}/references/23-gongfa-system.md
```

## 并行执行方式

10+1 个 subagent_spawn 同时发出，每个独立执行：

```
调用 10 次 subagent_spawn(type="research")（+Agent 11 按需）
  Agent 1,2,2b,6,9 → model="heavy"（深度推理）
  Agent 3,4,5,7,8,10 → model="light"（描述性提取）
  Agent 11（可选）→ model="light"（仅道医/养生家）

等待全部返回 → 检查每个是否写入了文件 → 进入 Phase 2
```

## 如果使用本地语料

当用户提供讲稿文件（PDF/Markdown/TXT），在 Agent task 中直接指定源文件路径。这样 Agent 不需要通过网络搜索，只需分析本地内容。本地语料质量远高于网络搜索。
